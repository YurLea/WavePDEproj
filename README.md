# Колебания струны 

Небольшое веб-приложение для визуализации колебаний струны и сравнения **численного** решения волнового уравнения с **аналитическим**, заданным пользователем.

## Математическая модель

$$
u_{tt} = a^2 u_{xx}, \quad t>0,\; 0<x<l
$$

$$
u(0,x)=\varphi(x), \quad u_t(0,x)=\psi(x)
$$

$$
u(t,0)=0, \quad u_x(t,l)=0
$$

## Возможности
- Ввод начальных условий: **φ(x)** и **ψ(x)**
- Ввод параметров: **a** и **l**
- Ввод формулы **u(t,x)** (аналитическое решение) для сравнения с численным
- Анимация колебаний (Canvas), пауза/продолжение
- Метрики расхождения: `δ_max`, `δ_mean`
- Подсветка точки максимального расхождения (опционально)

## Правила ввода выражений
Используется синтаксис библиотеки **mathjs**.

Допускается:
- переменные: `x`, `t`
- константы: `pi`, `e`
- операции: `+ - * / ^` и скобки
- функции: `sin() cos() tan() sqrt() abs() exp()`

Важно:
- тригонометрия — **в радианах**
- умножение писать явно: `2*x`, а не `2x`

Пример:
- `phi(x) = sin(pi*x/l)`
- `psi(x) = 0`
- `u(t,x) = sin(pi*x/l) * cos(a*pi*t/l)`

## Численный метод (кратко)
Используется явная конечно-разностная схема (2-й порядок):

$$
u_i^{n+1} = 2u_i^n - u_i^{n-1} + r\(u_{i+1}^n - 2u_i^n + u_{i-1}^n),
\quad
r = \left(\frac{a\Delta t}{\Delta x}\right)^2
$$

Границы:
- $u(t,0)=0 \Rightarrow u_0^n = 0$
- $u_x(t,l)=0 \Rightarrow u_N^n = u_{N-1}^n$

Параметры сетки в коде:
- `dx = 0.0025`
- `dt = (0.5 * dx) / a`  (то есть $\lambda = a\Delta t/\Delta x = 0.5$)

## Метрики отклонения
Сравниваются два дискретных решения $u_1(i)$ и $u_2(i)$:

$$
S = \max_i\left(|u_1(i)|,\;|u_2(i)|\right)
$$

$$
\delta_i = \frac{|u_1(i)-u_2(i)|}{S+\varepsilon},
\quad
\varepsilon = 10^{-12}
$$

$$
\delta_{\max} = \max_i \delta_i,
\quad
\delta_{\text{mean}} = \frac{1}{n}\sum_{i=0}^{n-1}\delta_i
$$

Примечание: при очень малой амплитуде решения $S$ становится маленьким, поэтому **нормированная**
ошибка может давать всплески даже при небольшой абсолютной разности.
